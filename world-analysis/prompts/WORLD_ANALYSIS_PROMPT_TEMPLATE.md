# 世界観考察・執筆用プロンプト（テンプレート）

このテンプレートに沿って情報を記入して渡してください。カード根拠と執筆条件を揃えることで、すぐにMarkdown記事を作成できます。

## 1. 目的と読者
- 目的: （例）世界観の深掘り/新規プレイヤー向け解説/既存ファン向け考察
- 読者: （例）初学者/中級者/コアファン

## 2. 記事テーマ
- 対象（必須・複数可）: 大陸/勢力/キャラクター/神器・アイテム/出来事/謎/年表
- 今回の焦点（1文）: （例）アクアノーヴァの支配構造と贋作の意味

## 3. 狙い（仮説の軸）
- 主仮説（1–3個）: （例）贋作は本体起動の鍵／天候支配＝インフラ制圧
- 反証可能性の扱い: （例）代替仮説も提示してバランスを取る

## 4. 事実ソース（必須）
以下のいずれかの形式で十分です。混在可。
- 引用カード（推奨）: `cardId / name / 根拠となるフレーバー要約 or 原文`
  - 例: `BT1-11 / ミカヅキ / 神器の力で式神・テンゲイを顕現し支配`
  - 例: `BT1-18 / 式神・テンゲイ / 天候操作→洪水→制圧`
  - 例: `BT2-14 / 神器の真相 / 奪還品は贋作だった`
- ファイル参照: `CNP_TCG_STORY_ANALYSIS.md` の該当箇所、`src/data/cards.json` の該当カード群
- 既存自作記事: ファイル名（例）`ARTICLE_2025-08-23_why-cnp-fights.md`
- 公式情報: PV/告知/画像のURLや要約

## 5. 制約・表記ルール
- 文量: （例）1,600–2,000字
- 見出し: h2/h3中心（h1はタイトルのみ）
- トーン:
  - **MD版**: フォーマルな分析調（アーカイブ・参照用）
  - **投稿版**: カジュアルで親しみやすい口語調（「〜ですね」「〜なんですよね」「おそろしやー」等）
- 文章スタイル: **箇条書き厳禁**。流れのある narrative（物語的）文章で書くこと
  - ❌ 悪い例: 「・神が暴走した。・住民が対立した。・街が崩壊した。」
  - ✅ 良い例: 「神が暴走したことで、住民たちは対立し、やがて街全体が崩壊へと向かっていきました。」
- カード注記: 文末に`(BT1-11)`形式で表記（変更可）
- 画像: プレースホルダー「画像」+キャプションを**必ず残す**（投稿時に実際の画像を挿入）
- 禁止事項: 事実と仮説の混同/断定的憶測/未公開情報の想定

## 6. アウトラインの希望（任意）
- 例（デフォルト）:
  1) はじめに（読者への語りかけ・記事の目的）
  2) 事実編（公式・カード根拠）— **流れのある文章で記述**
  3) 重要カード引用（各引用に画像プレースホルダー+キャプション）
  4) 考察編（仮説と代替仮説、反証可能性）
     - **重要**: 事実の再整理ではなく、カードに明示されていない「真の推測・仮説」を提示すること
     - 例: カゲロウの過去の推測、ツミカの隠された計画、未来の展開予測など
  5) 未解決の謎/今後の注目点
  6) まとめ（読者への問いかけ・今後への期待）
  7) 出典カード一覧（IDと短文）

## 7. 出力仕様
- 形式: Markdown
- 構成: 上記アウトラインに沿う（希望があれば優先）
- 見出し: h2=章、h3=小見出し
- 引用: `> 引用文（カード名/ID）`
- 最後に「出典カード一覧」を列挙
- 必要ならフロントマター（title/date/author/tags）を付与（指定時）

## 8. 追加オプション（任意）
- フロントマター: `title:`, `date:`, `author:`, `tags: [考察, 大陸名]`
- SEOメタ: スラッグ/ディスクリプション案
- 表記縛り: ひらがな/漢字バランス、句読点、英数字表記

## 重要な執筆ポイント（カグツチ記事から学んだこと）

### ✅ 良い書き方
1. **文章の流れ**: 接続詞で段落をつなぎ、物語のように読ませる
   - 例: 「この悲劇を引き起こしたのは、セイドウ幹部カゲロウです。元破戒僧という異色の経歴を持つ彼は、神器の力を用いて...」

2. **読者との対話**: カジュアルな語りかけ・共感表現を入れる
   - 例: 「おそろしやー」「温泉入ってる場合かな～」「これは悲しいなぁ」

3. **画像の効果的配置**: 重要なカード・シーンに画像+キャプション
   - 例: 「画像\n元破戒僧って、何があった？」

4. **考察の深さ**: カードに明示されていない背景・心理・未来を推測
   - 良い例: 「カゲロウ自身が過去に『信仰』によって裏切られた経験があるのではないでしょうか」

### ❌ 避けるべき書き方
1. **箇条書きの羅列**: 「・神が暴走した。・住民が対立した。」
2. **事実の単純再整理**: カードの内容をそのまま並べるだけの考察
3. **硬すぎる文体**: 「〜である。〜である。」の連続
4. **画像なし**: テキストのみで視覚的要素が不足
